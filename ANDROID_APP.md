# Nivora Android App Conversion

Nivora uses Capacitor to package the existing React + Vite application as an Android app. The finance domain remains shared with the web/PWA version.

## Architecture

```text
React + Vite
     |
     +-- Web / PWA
     |
     +-- Capacitor
            |
            +-- Android
```

## Android identity

- App name: Nivora
- Application ID: `com.nivora.finance`
- Web output: `dist`
- Android scheme: HTTPS

## Local setup

Prerequisites:

- Node.js
- Android Studio
- Android SDK
- A configured Android emulator or USB-debuggable test device
- Java/JDK compatible with the installed Android Gradle tooling

From the repository root:

```bash
npm install
npm run build
npm run cap:add:android
npm run cap:sync
npm run cap:open:android
```

After the Android project is created, use Android Studio to run Nivora on an emulator or device.

You can also use:

```bash
npm run cap:run:android
```

## Important

The `android/` directory is intentionally generated by Capacitor rather than hand-written through the web repository workflow. Run `cap:add:android` locally once to create the native Android project, then commit the generated project when it has been validated.

Do not put financial business logic in Android-specific code. Native code should provide platform capabilities while the shared React/domain layer remains the product core.
