# Phase 3 — Savings

Nivora now has a local-first Savings Center built around real contribution data.

## Included
- Savings goal model with target, saved amount, optional target date and progress.
- Contribution and withdrawal history with localStorage persistence.
- Total saved and current-month saved calculations.
- Savings-rate calculation from recorded income and expenses.
- Goal progress bars and estimated completion when enough contribution history exists.
- Add savings and withdraw savings flows with validation.
- Dedicated Savings and Goals navigation surfaces.
- Premium responsive UI consistent with the Nivora design system.

## Data honesty
Savings totals come from saved savings entries. Savings rate comes from recorded transaction income and expenses. No placeholder financial insights are generated.

## Future phases
Budgeting will use the same centralized finance domain, while analytics can later combine transactions and savings history.
