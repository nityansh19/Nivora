# Phase 13 — Onboarding + Authentication

Nivora now opens with a premium authentication gate and first-run onboarding.

## Authentication
- Sign in / create account UI
- Email and password validation
- Auth state persistence for the local prototype
- No real credentials are transmitted or stored remotely yet

## Onboarding
- Name
- Primary account name/type
- Opening balance
- Expected monthly income
- Monthly spending budget
- Monthly savings target
- Review step
- Completion persistence
- Primary account is created automatically when none exists

## Product direction
This phase intentionally establishes the UX and local state boundary for authentication. A production authentication provider, secure password handling, sessions, cloud storage and multi-device sync belong to the upcoming cloud/auth architecture phase.
